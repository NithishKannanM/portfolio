## The idea

Adaptive learning systems typically adapt on correctness: get it right, move
on; get it wrong, remediate. That misses the case every teacher recognises — a
learner who is answering correctly but is frustrated, or answering incorrectly
but engaged and close.

Empath adds emotional state as an input to the adaptation decision, so the
platform can respond to *how* the learning is going, not only whether the last
answer was right.

## Build

- **React** front end.
- **FastAPI** backend.
- **HuggingFace** models for the emotion signal.
- **Supabase** for data and auth.

## Result

3rd place, BIS National Hackathon 2025.
